This work uses search-engine results to add context for Chinese named entity recognition. A query derived from the input sentence retrieves related texts, which a multi-channel semantic fusion model combines with the original sentence.

The evaluation covers four NER datasets spanning formal writing and social media, with applications to big-data content security.
