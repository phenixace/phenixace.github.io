MolViBench evaluates code generated by language models for molecular research. It contains 358 tasks across five cognitive levels and 12 drug-discovery workflows, ranging from individual API calls to virtual-screening pipelines.

The evaluation combines type-aware output comparison with AST-based API-semantic analysis to assess execution and chemical correctness. The study tests nine coding models and compares three molecular coding workflows.
